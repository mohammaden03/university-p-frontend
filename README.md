# سامانه هوشمند بازشناسی و جستجوی نسخه‌های خطی کهن فارسی و عربی (HTR & OCR Platform)

> **عنوان پروژه دانشگاهی:**  
> «طراحی و پیاده‌سازی سامانه هوشمند بازشناسی متن (HTR/OCR)، خوانش و جستجوی پیشرفته در نسخه‌های خطی فارسی و عربی با خطوط خوشنویسی اسلامی (نستعلیق، شکسته، نسخ و کوفی)»  
> *Design and Development of an Intelligent HTR/OCR System for Recognition, Reading, and Advanced Search in Persian and Arabic Manuscripts with Islamic Calligraphy.*

---

## ۱. معرفی و معماری سامانه

این سامانه یک پلتفرم جامع و دانشگاهی جهت دیجیتال‌سازی، نویسه‌خوانی هوشمند (HTR)، تصحیح مشارکتی، تولید دادگان استاندارد (Ground Truth) و جستجوی پیشرفته تمام‌متن در نسخ کهن خطی فارسی و عربی است.

### ساختار ارتباطی ۳ لایه (Three-Tier Architecture):
```
┌─────────────────────────────────┐
│     واسط کاربری پژوهشگر         │
│   React 19 + TypeScript + Vite  │
│   Persian RTL + Vazirmatn Font  │
└────────────────┬────────────────┘
                 │ HTTP / REST (Bearer JWT)
                 ▼
┌─────────────────────────────────┐
│        بک‌اند NestJS API         │
│  احراز هویت، اعتبارسنجی اسناد،  │
│  مدیریت نسخ، پایگاه داده PostgreSQL│
└────────────────┬────────────────┘
                 │ gRPC / Queue / Celery
                 ▼
┌─────────────────────────────────┐
│     موتور هوش مصنوعی (پایتون)    │
│  مدل‌های یادگیری عمیق Vision    │
│  و ترنسفورمرهای HTR خوشنویسی     │
└─────────────────────────────────┘
```
> **توجه مهم:** کلاینت فرانت‌اند بر اساس اصول استاندارد امنیتی صرفاً با سرویس **NestJS** در ارتباط است و هرگز به شکل مستقیم با سرویس استخراج پایتون ارتباط برقرار نمی‌کند.

## ۲. ویژگی‌های کلیدی پیاده‌سازی شده

1. **طراحی اصیل دانشگاهی و راست‌چین (Persian RTL):**
   - قلم استاندارد **وزیرمتن (Vazirmatn)** به عنوان قلم پایه و **امیری (Amiri)** برای خطوط کهن.
   - رنگ‌بندی موقر کتابخانه‌ای: پس‌زمینه کرم/کاغذ دست‌ساز کهن (`#FDFBF7` / `#FAF8F5`)، رنگ متن دودی مرکبی (`#1E232A`) و لهجه‌های زمردی و فیروزه‌ای.
   - تفکیک خودکار و جهت‌دهی صحیح برای شناسه‌ها و رایانامه‌های انگلیسی بدون واژگونی متنی.

2. **احراز هویت و سطوح دسترسی بر اساس نقش (RBAC):**
   - مدیر ارشد سامانه (`admin`)، پژوهشگر ارشد (`researcher`)، مصحح و برچسب‌گذار (`annotator`).
   - ذخیره‌سازی توکن امن کوتاه‌مدت، پاک‌سازی هنگام خروج یا انقضای نشست (۴۰۱).
   - مسیرهای محافظت‌شده (`ProtectedRoute`).

3. **گنجینه و کتابخانه نسخ خطی:**
   - نمایش شبکه‌ای (Grid) و جدولی (Table).
   - فیلتر هم‌زمان بر اساس زبان (فارسی، عربی، ترکیبی)، سبک خط (نستعلیق، شکسته، نسخ، کوفی، ثلث، تعلیق) و دوره تاریخی (تیموری، صفوی، ایلخانی و...).
   - فرم‌های ثبت و ویرایش نسخه همراه با اعتبارسنجی فرم‌ها با **Zod**.
   - حذف و بایگانی ایمن با کادر تأیید.

4. **کارگاه تصحیح و مقابله متن (Transcription Editor):**
   - واسط دوردیفه متمرکز (تصویر نسخه در کنار ویرایشگر متن).
   - بزرگ‌نمایی (Zoom)، چرخش و پیمایش تصویر برگه.
   - نمایش کادرهای پیرامونی سطور بازشناسی شده (Bounding Boxes) با قابلیت کلیک همگام.
   - نوار ابزار ثبت سریع اِعراب و علائم خوشنویسی (ـَ ـُ ـِ ـً ـٍ ـٌ ـّ ـْ ـٰ).
   - مقابله تطبیقی نسخه اولیه هوش مصنوعی و نسخه تصحیح‌شده همراه با محاسبه برخط **CER** (نرخ خطای کاراکتر) و **WER** (نرخ خطای کلمه).
   - تاریخچه کامل نسخه‌های بازنگری شده همراه با نام مصحح و تاریخ.

5. **گردش کار بارگذاری و بازشناسی برگه (Upload & Recognition Workflow):**
   - بارگذاری با کشیدن و رها کردن (Drag & Drop) با پیش‌نمایش متناسب.
   - انتخاب مدل اختصاصی HTR و زبان کتابت.
   - پایش چرخه‌ای و واقعی وضعیت فرآیند (Queued → Processing → Completed).

6. **جستجوی پیشرفته تمام‌متن (Full-Text Search):**
   - جستجوی بلادرنگ در اشعار و عبارات نسخ با نرمال‌سازی حروف عربی/فارسی و حذف اِعراب.
   - استخراج بریده متنی با برجسته‌سازی کلمه جستجو شده و امکان جهش مستقیم به کارگاه تصحیح.
   - همگام‌سازی کامل با پارامترهای آدرس مرورگر (URL Query Params).

7. **مدیریت دادگان آموزشی (Dataset Split & Leakage Prevention):**
   - تفکیک برگه‌ها به دسته‌های آموزش (Train)، اعتبارسنجی (Validation) و ارزیابی (Test).
   - **شناسایی و هشدار هوشمند نشت داده (Data Leakage):** جلوگیری از تفکیک برگه‌های یک نسخه خطی بین دسته‌های آموزش و آزمون.
   - استخراج ساختار داده به صورت فایل JSON استاندارد آماده برای آموزش مدل‌های PyTorch/HuggingFace.

## ۳. پشته فناوری (Technology Stack)

- **React 19 & TypeScript (Strict Mode)**
- **Vite 8 & Tailwind CSS v4**
- **React Router 7**
- **TanStack Query (React Query) v5** جهت مدیریت درخواست‌ها و کش سمت کلاینت
- **Axios** با رهگیرهای (Interceptors) ارسال توکن و ترجمه خطاهای سرور
- **React Hook Form & Zod** برای مدیریت و اعتبارسنجی فرم‌ها
- **Lucide React** آیکون‌های مینیمال
- **Node:Test & TSX** برای آزمون‌های منطق پایه و اعتبارسنجی

## ۴. راه‌اندازی و اجرای پروژه

### پیش‌نیازها:
- Node.js نسخه 20 به بالا
- npm نسخه 10 به بالا

### مراحل اجرا در محیط محلی:
```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه (همراه با API ماک کامل NestJS و فرانت‌اند)
npm run dev
```
سامانه بر روی درگاه `http://localhost:3000` در دسترس خواهد بود.

### اجرای آزمون‌های واحد (Unit Tests):
```bash
npx --yes tsx --test src/utils/textUtils.test.ts src/utils/datasetRules.test.ts src/utils/validation.test.ts
```

### ساخت نسخه نهایی برای انتشار (Production Build):
```bash
npm run build
```

### اجرای کانتینری با داکر (Docker & Docker Compose):
```bash
docker-compose up --build
```

## ۵. پیکربندی متغیرهای محیطی (`.env`)

فایل نمونه در مسیر `.env.example` قرار دارد:
```env
# نشانی پایه سرور NestJS
VITE_API_BASE_URL="http://localhost:3000/api/v1"
```
در صورتی که بک‌اند NestJS روی درگاه یا دامنه دیگری قرار دارد (مثلاً `http://api.manuscript-htr.ir/api/v1`)، کافی است مقدار متغیر فوق را تغییر دهید.
